# Image credits and publication notes

This project is an independent, unofficial tribute concept. Photographs used for *prototype visualization* are derived from user-supplied reference files.

- `assets/hero-portrait.webp`: optimized from `portrait-01.jpg` in the attached source kit. Rights not established.
- `assets/result-portrait.webp`: optimized from `portrait-02.jpg` in the attached source kit. Rights not established.
- `assets/archive-portrait.webp`: optimized from `archive-1988-portrait.jpg`, which was downloaded from the Wikimedia Commons media archive (image-specific copyright restrictions and attribution should be checked again for each distribution country).
- `assets/archive-friends.webp`: optimized archival photo, currently unused. Rights must be checked.
- `assets/graphic-collage.webp`: optimized design reference, currently unused. Rights not established.
- `assets/paper-texture.webp`: user-supplied project texture.

No source photography is claimed as original to this project. **Do not distribute/deploy the photographed assets publicly until permissions and attribution are verified.** Replacing photo files with licensed assets at the same paths will preserve the layout.

Content: Creative drafts inspired by Tupac's songs. Some titles in the research catalog are not verified audio works; unpublished and alternative titles must be reviewed before release.
